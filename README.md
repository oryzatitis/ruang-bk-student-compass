# Ruang Bk Student Compass

Buatkan saya website bernama RUANG BK untuk SMP Negeri 3 Tempel.

Website ini digunakan oleh guru Bimbingan dan Konseling untuk mengelola:

1. Data siswa

2. Daftar hadir siswa

3. Kunjungan BK

4. Konseling individu

5. Konseling kelompok

6. Pelanggaran dan pembinaan

7. Program BK dan RPL

8. Angket AKPD

9. Dokumen BK

10. Laporan BK

Gunakan Bahasa Indonesia. Buat tampilan yang sederhana, rapi, berwarna biru dan putih, mudah digunakan oleh guru pemula, serta nyaman dibuka melalui laptop dan HP.

Buat menu yang mudah dipahami. Saya ingin aplikasi yang benar-benar dapat menyimpan data, memiliki login, dan dapat mencetak laporan.
